# Maker Console listing

## Name

WLED Live Control

## Description

Control your WLED lights directly from Stream Deck, with no cloud account, hub, or Home Assistant required. WLED Live Control talks to your devices over your local network, and keys and dials update live, even when you make changes in the WLED app.

**Actions**

- Power: toggle, on, or off
- Brightness: set a level or step up and down
- Color: pick a color, or dial in hue and saturation
- Effect and Palette: choose one, step through them, or go random
- Effect Speed / Intensity: adjust speed, intensity, and custom sliders
- Preset: apply saved presets and playlists
- Custom JSON: send any WLED JSON API command

**Features**

- Finds WLED devices on your network automatically, or enter an IP address
- Each action can target its own device and segment
- Works on keys and on Stream Deck + dials and touch strip
- Includes ready-made profiles for Stream Deck (15-key) and Stream Deck +

**Requirements**

Stream Deck 7.1 or later on macOS 12+ or Windows 10+, and a device running WLED 0.14 or later on your local network. On macOS, allow Stream Deck under Privacy & Security > Local Network.

WLED Live Control is an independent project and isn't affiliated with the WLED project.

## Release notes

First Marketplace release. Control power, brightness, color, effects, palettes, effect speed and intensity, and presets on your WLED devices, with live status on keys and dials.
